1 Hai tài liệu

Bộ tài liệu chia làm hai phần theo mục tiêu bài toán: phân tích yêu cầu & phân rã chức năng (làm gì) và thiết kế hệ thống (làm như thế nào).

Tài liệu 1 — Phân tích & Phân rã chức năng

  • Tổng quan hệ thống & bối cảnh nghiệp vụ
  • Tác nhân hệ thống (4 vai trò)
  • 16 yêu cầu chức năng + 9 yêu cầu phi chức năng
  • Cây phân rã chức năng 5 cấp (FBD)
  • Đặc tả 5 use case trụ cột
  • Vòng đời trạng thái đơn hàng
  • 25 quy tắc nghiệp vụ (BR-01 → BR-25)
  • Ma trận truy vết FR ↔ Task ↔ Endpoint

→ Mở tài liệu Phân rã chức năng

Tài liệu 2 — Thiết kế hệ thống

  • Kiến trúc tổng thể 6 tầng
  • Ranh giới module + ma trận phụ thuộc
  • Thiết kế CSDL: 13 bảng trên 5 schema
  • ERD tách theo từng schema + quan hệ logic
  • Luồng kỹ thuật: request HTTP, hủy đơn, aggregate root
  • 2 cơ chế giao tiếp liên module: Contract & Domain Event
  • Xử lý lỗi, validation, chuẩn response
  • Hạ tầng, CI, quy trình Git

→ Mở tài liệu Thiết kế hệ thống

3 Quy ước dùng chung

Định danh

  • FR-xx — yêu cầu chức năng
  • NFR-xx — yêu cầu phi chức năng
  • BR-xx — quy tắc nghiệp vụ
  • UC-xx — use case
  • N2LHTBLTT-xx — task Jira

Module & schema

  • Identity → identity
  • Catalog → catalog
  • Cart → cart
  • Order → ordering
  • Inventory → inventory

Cấp độ trong cây FBD

  • Cấp 0 — mục tiêu hệ thống
  • Cấp 1 — chức năng theo vai trò
  • Cấp 2 — nhóm chức năng nghiệp vụ
  • Cấp 3 — chức năng con (FR)
  • Cấp 4 — thao tác cụ thể (endpoint)

4 Trạng thái hiện thực

9 / 16 FR đã có endpoint + test

FR-01 → FR-09 và FR-12. Mỗi FR đều có đường dẫn HTTP thật và test tự động bảo vệ hành vi.

7 / 16 FR đã có cơ chế domain

FR-10, 11, 13, 14, 15, 16 còn thiếu controller nhưng đã có entity, method domain và contract — phần việc còn lại chủ yếu là wiring.

168 test tự động

35 unit · 7 architecture · 126 integration. Tất cả chạy trong CI với PostgreSQL thật.
