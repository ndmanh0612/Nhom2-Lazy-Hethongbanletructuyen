🗂 7 task của bạn — bấm để xem chi tiết

Phạm vi phụ trách của bạn: toàn bộ module Cart và Order (Domain → Repository → Service → API), hạ tầng dùng chung Swagger / Validation / Global Exception, và toàn bộ bộ kiểm thử tích hợp. Ngoài ra bạn phụ trách task 39 (regression test) — đây là task bạn nhận thêm sau đợt export Jira ngày 25/10.

🎯 Điều bạn cần nắm vững

1 · Domain thuần túy

Entity Cart, CartItem, Order giữ toàn bộ luật nghiệp vụ. Không reference EF Core, không throw HTTP exception.

2 · Contract giữa module

Order không biết Cart/Inventory/Catalog. Chỉ nói chuyện qua ICartContract, IInventoryContract, IProductPricingContract.

3 · Event Bus

Hủy đơn → phát OrderCancelled → MediatR → Inventory hoàn tồn. Loose coupling giữa các module.

4 · Error chuẩn

Mọi lỗi đi qua AppExceptionMiddleware → ErrorResponse có code + requestId.

5 · Test thật

Integration test dựng WebApplicationFactory + PostgreSQL thật, mỗi lần chạy một database riêng rồi xoá.

6 · Git workflow

Branch feature/N2LHTBLTT-<số>, commit Conventional Commits kèm mã Jira, PR vào develop.
